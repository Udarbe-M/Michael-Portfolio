# Michael O. Udarbe Jr. — Portfolio

A cinematic, accessible portfolio for Michael O. Udarbe Jr., built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Three.js.

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run test
npm run build
```

## Project covers

Temporary branded SVG covers live in `public/projects/`. Replace them with the final user-supplied 16:9 project images while preserving the matching filenames or update the paths in `src/data/portfolio.ts`.

Recommended source size: 1600 × 900 pixels or larger. Use optimized WebP, AVIF, PNG, or JPEG assets.

## Deployment

Vercel framework preset: Vite

- Build command: `npm run build`
- Output directory: `dist`
- Environment variables: none
